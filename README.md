# Stephen Ejimchukwu | Portfolio

Single-page portfolio built with React, TypeScript, Vite and Tailwind CSS.

## Run locally
```
npm install
npm run dev
```

## Build
```
npm run build
```
The production files are created in `dist/`.

## Deploy on Vercel
Push the project to GitHub, then in Vercel choose **Add New > Project**, import the repository and click **Deploy**.
Vercel detects Vite automatically; `vercel.json` already sets the build command (`npm run build`) and output folder (`dist`).
No environment variables are needed.
